About

I'm a software developer who mostly works on the backend: APIs, authentication and permissions, databases and the infrastructure that runs them.

I design NestJS services with TypeORM, ship them in Docker Compose setups, and write systems-level code in C and C++, including an HTTP server and a Unix shell.

I review code, learn from my peers, research what I don't know yet, and work well in a team. I led the technical side of a five-role, full-stack pet adoption platform with a team of five.
